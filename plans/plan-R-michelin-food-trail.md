# 🍽️ Plan R — Michelin & Bib Gourmand Food Trail (Nov 1–9, 2026)

**Shape:** One Michelin-listed (star, Bib Gourmand, or Michelin Selected) meal anchors most days, paired with the nearest verified sightseeing so it stays one walking cluster. Sunday closures hit this plan hardest (Hadongkwan, Pildong Myeonok, Chanyang-jip all closed Sun) — Sunday is deliberately the rest day. Pace: 🟥 busy · 🟨 moderate · 🟩 easy.

**Busy days:** Nov 2, 5, 7 · **Easy days:** Nov 1, 4, 9

| Date | Day / pace | Cluster (stay inside it) | Plan |
|---|---|---|---|
| **Nov 1** | Sun 🟩 | Myeong-dong arrival | ⛔ **Hadongkwan closed Sun** — save it for Wed/Sat. Check-in → [Myeongdong Cathedral](https://www.mdsd.or.kr) → dinner ⭐ **[Myeongdong Kyoja](https://guide.michelin.com/en/seoul-capital-area/kr-seoul/restaurant/myeongdong-kyoja)** (Michelin Selected, kalguksu/mandu since 1966, daily 10:30–21:00) → [NANTA](https://www.nanta.co.kr/kr/show/detail.php?id=1) 17:00/20:00. |
| **Nov 2** | Mon 🟥 | Bukchon — Hwangsaengga (Bib Gourmand) | [Gyeongbokgung](https://royal.khs.go.kr) guard 10:00 + palace (open Mon) → lunch ⭐ **[Hwangsaengga Kalguksu](https://guide.michelin.com/en/seoul-capital-area/kr-seoul/restaurant/hwangsaengga-kalguksu)** (**Bib Gourmand 2026**, daily 11:00–21:30) → [Bukchon](https://hanok.seoul.go.kr) alleys before 17:00 (Red Zone curfew) → [Insadong](https://mediahub.seoul.go.kr/archives/1270460). |
| **Nov 3** | Tue 🟨 | Seochon — Imun Seolnongtang (1907) | [Changdeokgung + Huwon](https://www.cdg.go.kr) morning (open Tue) → walk Seochon [Tongin Market](https://tonginmarket.co.kr) → dinner ⭐ **[Imun Seolnongtang](https://guide.michelin.com/en/seoul-capital-area/kr-seoul/restaurant/imun-seolnongtang)** (Michelin Selected, Seoul's first registered restaurant, 1907; Mon–Sat 08:00–21:00 break 15:00–16:30, Sun to 20:00) → optional Yeouido [BANKSY](https://thehyundaiseoul.ehyundai.com/culture/alt1) last day if time allows. |
| **Nov 4** | Wed 🟩 | Namsan — Hadongkwan (1939) | **0 transit start.** Early lunch ⭐ **[Hadongkwan](https://guide.michelin.com/en/seoul-capital-area/kr-seoul/restaurant/hadongkwan)** gomtang since 1939 (Mon–Sat 07:00–16:00, **closed Sun**, sells out — go before noon) → [Namsan Cable Car](https://www.cablecar.co.kr) → [N Seoul Tower](https://www.nseoultower.co.kr) → [Namsangol Hanok Village](https://www.hanokmaeul.or.kr/ko/guide). Easy afternoon. |
| **Nov 5** | Thu 🟥 | Gangnam — Budnamujip (Michelin Selected) | [Seonjeongneung](https://royaltombs.cha.go.kr/multiBbz/selectMultiBbzView.do?id=61&no=61&bbzId=tombs&mn=RT_01_08_03) tombs docent tour → lunch ⭐ **[Budnamujip](https://guide.michelin.com/en/seoul-capital-area/kr-seoul/restaurant/budnamujip)** (Seocho, beef BBQ since 1977, Michelin Selected, daily 11:00–21:30) → ⭐ [Bongeunsa Temple Life](http://temple.bongeunsa.org/public_html/explain/temple_life.asp) 14:00–16:00 → [Starfield Library](https://starfield.co.kr/m/coexmall/starfieldLibrary/library.do) + [Food Week Korea](https://www.foodweek.co.kr/). |
| **Nov 6** | Fri 🟨 | DDP — Geumdwaeji Sikdang (Bib Gourmand) | Walk to DDP → [Dream in Light](https://culture.seoul.go.kr/culture/culture/cultureEvent/view.do?cultcode=156491&menuNo=200013) 18:00/19:00 → Line 2 one stop to Sindang for dinner ⭐ **[Geumdwaeji Sikdang](https://guide.michelin.com/en/seoul-capital-area/kr-seoul/restaurant/geumdwaeji-sikdang)** (**Bib Gourmand 2026**, bone-in samgyeopsal, daily 11:30–23:00, in-person queue only). |
| **Nov 7** | Sat 🟥 | Namsan side — Pildong Myeonok (Bib Gourmand) | Late-morning [Hoehyeon]-side stroll → lunch ⭐ **[Pildong Myeonok](https://guide.michelin.com/en/seoul-capital-area/kr-seoul/restaurant/pildong-myeonok)** (**Bib Gourmand 2026**, naengmyeon, 11:00–15:00/17:00–20:20, **closed Sun** — this is the Saturday slot) → afternoon [Ahn Junggeun Memorial Hall](https://mediahub.seoul.go.kr/archives/2013777) → evening: pick ONE Sat headline from the clash table below, or stay food-focused with a second Bib-worthy dinner. |
| **Nov 8** | Sun 🟨 | Jung-gu east — Woo Lae Oak (Bib Gourmand, open Sun) | ⛔ Chanyang-jip and several Sunday-closed spots skipped by design. Lunch/early dinner ⭐ **[Woo Lae Oak](https://guide.michelin.com/en/seoul-capital-area/kr-seoul/restaurant/woo-lae-oak)** (**Bib Gourmand**, Pyongyang naengmyeon since 1946, Tue–Sun 11:30–21:30, **closed Mon** — open on this Sunday) near Euljiro 4-ga → Hyehwa → [Naksan Park](https://parks.seoul.go.kr) → ⭐ [Mulbit Yeonhwa](https://www.kh.or.kr/cms/content/view/1526) **FINAL night**. |
| **Nov 9** | Mon 🟩 | Checkout — last Hadongkwan | ⭐ **[Hadongkwan](https://guide.michelin.com/en/seoul-capital-area/kr-seoul/restaurant/hadongkwan)** 07:00 opening (sells out) — the plan's bookend meal. Check-out 12:00. [Gyeongbokgung](https://royal.khs.go.kr)/[MMCA Seoul](https://www.mmca.go.kr) if time (both open Mon). |
